# 테스트 시나리오

`python -m src.main`을 실행하고 각 프롬프트를 입력합니다. 실제 도구 호출을 예상 도구 호출과 비교합니다.
순서는 조금 달라도 됩니다. 중요한 것은 에이전트가 추측하지 않고 도구를 쓰는지입니다.

도구를 만들기 **전에** 씁니다 (과제 5). A–C 행은 필수입니다.

| # | 종류 | 프롬프트 | 예상 도구 호출 | 확인할 것 |
|---|---|---|---|---|
| A | 도구 3개 연결 | <프롬프트> | `<도구>` → `<도구>` → `<도구>` | <올바른 최종 답> |
| B | 오류 회복 | <이름이나 값이 틀린 프롬프트> | `<도구>` → 오류 → `<도구>` | 회복하고 문제를 설명함 |
| C | write 전 확인 | <프롬프트> | (확인 질문) → `<write 도구>` | 먼저 확인하고, "네" 다음에 데이터가 바뀜 |
| D | <자유> | <프롬프트> | <...> | <...> |

> write 도구를 테스트한 뒤에는 데이터를 원래대로 돌려놓습니다. 바뀐 `data/*.json` 파일을 복원하세요. 테스트를 시작하기 전에 `data/` 폴더를 복사해 두면 됩니다.
